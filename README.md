# WebCurrículo — Fernando Dias

Webcurrículo desenvolvido para apresentar minha trajetória acadêmica e profissional, conhecimentos técnicos, projetos e formas de contato, reunindo informações relevantes sobre minha formação e experiência na área de tecnologia.

## Sobre o projeto

O projeto foi desenvolvido como uma página pessoal para funcionar como uma versão online do meu currículo, utilizando tecnologias fundamentais do desenvolvimento web.

A proposta é apresentar de forma simples e organizada:

*  Sobre mim
*  Experiência profissional
*  Formação acadêmica
*  Projetos desenvolvidos
*  Habilidades técnicas
*  Idiomas
*  Informações de contato

##  Tecnologias utilizadas

* HTML5
* JavaScript
* Bootstrap

## Objetivos

Além de servir como apresentação profissional, o projeto foi desenvolvido com o objetivo de colocar em prática conhecimentos de desenvolvimento web, estruturação semântica, estilização e organização de conteúdo

Também representa parte da minha evolução durante a graduação em Engenharia de Software, transformando conhecimentos adquiridos em projetos práticos.


Projeto desenvolvido como parte do meu portfólio pessoal e processo de aprendizado em desenvolvimento de software.
